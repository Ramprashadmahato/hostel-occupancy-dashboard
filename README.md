# Hostel Occupancy Dashboard
**Live demo:** https://hostel-occupancy-dashboard.streamlit.app/

A sample Streamlit analytics dashboard for a hostel business: occupancy,
revenue, and guest mix by month and room type, with filters.
All data is a built-in, illustrative sample.

This complements Ram's existing Hostel-Management-System project
(React / Node.js) with a Python data view of the same domain.

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy on Streamlit Community Cloud

Push to a public GitHub repo, then deploy from https://share.streamlit.io
with main file `streamlit_app.py`.
